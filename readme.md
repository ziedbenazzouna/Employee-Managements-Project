# Demo Project

Development of a web-based employee management solution
*Design and implementation of an onion architecture for a modular and maintainable application.
*Development and integration of an authentication and user management module using ASP.NET Identity.
*Implementation of employee management via REST Web API and Angular (CRUD, image display, Excel export).
*Setup of a continuous integration pipeline with GitHub Actions.
*Application deployment and project management on Azure DevOps.
Technical environments: ASP.NET Core, REST Web API, C#, Angular, Visual Studio 2022, Visual Studio Code, SQLite, Azure DevOps.
